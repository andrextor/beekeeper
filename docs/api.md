# API contract — Landak Apiario

What the clients (`beekeeper-mobile`, `admin/`) may rely on. Everything here is enforced by the migrations in `supabase/migrations/` and proven by `supabase/tests/`. A breaking change is called out in `CHANGELOG.md` with **BREAKING**.

Clients use `@supabase/supabase-js` with the project URL and the **publishable key** only.

## Conventions

### Ids

`uuid` v4 generated by the client for every domain row, so rows can be created offline. The server never generates an id the app needs to know in advance.

### Timestamps

`timestamptz`, UTC on the wire (ISO 8601). `created_at` defaults to `now()`. `updated_at` is set by a trigger on every insert and update; any client value is ignored.

### Soft delete

Domain rows have `deleted_at`. Clients set it; they never send `DELETE`. Deleted rows still travel through the sync pull, so other devices learn about them.

### Errors

| Source | Shape | Client handling |
|--------|-------|-----------------|
| RPCs and triggers | `code = 'P0001'`, `message` in Spanish (shown as is), `details` = stable machine code | Branch on `details`, never on `message` |
| Unique violations | `code = '23505'`, constraint name in `message` | Map through the table below |
| RLS refusal on insert | `code = '42501'` | Permanent failure ("Requiere atención") |
| Network, 5xx, 429 | — | Retry with backoff |

An unmapped `23505` is shown as "Ya existe un registro igual.".

### Sync pull

Per table:

```sql
select * from <table>
where updated_at > :cursor
order by updated_at, id
limit 500
```

Repeat until a page returns fewer than 500 rows. The new cursor is the last row's `updated_at` **minus 2 minutes**: the overlap catches transactions that committed late, and local upserts by id make duplicates harmless.

### Sync push

`upsert` by `id` (`on conflict (id) do update`), which is idempotent: a retried request writes the same row. The outbox retries with backoff 5 s → 30 s → 2 min → 10 min (cap). A `P0001`, `23505`, `42501` or other 4xx marks the entry **Requiere atención**; retrying would never succeed.
